# CRM Travel Agent (B2B & B2C)

🚀 All-in-one CRM platform for Travel Agents, supporting B2B & B2C operations.

## Tech Stack
- Laravel 10
- MySQL / PostgreSQL
- Redis (Queue & Cache)
- Livewire / Blade
- Spatie Permission
- PDF Generator

## Core Modules
- CRM (Leads, Contacts, Companies)
- Quotation Engine
- Booking & Operation
- Finance & Payment
- Automation & Reporting

## Environment Setup
```bash
cp .env.example .env
php artisan key:generate
